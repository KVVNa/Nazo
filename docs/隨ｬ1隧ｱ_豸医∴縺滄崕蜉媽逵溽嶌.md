## 証言

- ソラ：「02:30ごろ機関区で火花を見た」— 勘違い（照明の点滅、時計のずれ）
- ドゥラン：「予備セルは交換した」— 嘘。部品在庫記録か取り外したセル、予備セルの実測残量を突きつけると告白する
- ケイ：「02:05に貨物室へ行った」— 本当。無関係
- ミナ：「B系の冷却ループは前から圧が不安定」— 本当

## 正解の仮説

- 原因の種類：事故・故障
- 具体的な出来事：冷却配管の亀裂から漏れた冷却液が配電盤を地絡させた
- 順番：冷却圧の低下 → 貨物室のドア → 機関区の明滅 → 主配電盤の遮断
- 関係人物：ドゥラン（事実を偽った・隠した）
- 対処：漏れを封止し、乾燥させてから主電源を再投入

## 対処ごとの結果

| 作戦 | 結果 |
|---|---|
| 封止→乾燥→再投入 | 原因を「冷却液の漏れ」としていれば解決。原因を取り違えると封止をせず、しばらくして再遮断（先に乗員が自分の判断で封止していれば解決） |
| 乾燥→再投入 | いったん復旧するが、漏れが続けば約20分で再遮断 |
| ただちに再投入 | 濡れた配電盤から発火。実行者が負傷し、床の冷却液痕が失われ、配電盤の修理が必要になる |
| 負荷の切り離し | 予備電源の消費が約4割減る |
| 予備セル交換 | 予備電源が満タンになる。取り外したセルが証拠になる |
| 拘束 | 見当違いなら全員の信頼が下がる |
